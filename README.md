# Proyecto Grupo 12 Optimización (ICS1113)

Primero deben tener los archivos en su computador, para ello, usan Git para descargar el repositorio en sus computadores personales:
1. Se van a la carpeta en la que quieren guardar el código y abren su terminal allí
    
    - [Tutorial Windows](https://youtu.be/HoMt5meIf7I?t=74): ver desde 1:14 hasta 1:40 nada más
    - [Tutorial Mac](https://youtu.be/VR9DyX6r5-A?t=52): ver desde 0:52 hasta 1:03 nada más.

2. Ejecutan el siguiente comando para copiar el repositorio
``` 
git clone https://github.com/mmaartinn/proyecto-opti.git
``` 

3. Asumiendo que se tienen instaladas las librerías de Gurobi, Pandas y Matlib (+ seaborn por el momento), lo único que hay que hacer para ejecutar el código es:

``` 
python3 Script\ Python/main.py
```

Y debería entregar una solución factible.
